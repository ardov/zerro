# Issue triage

Use one `Status:` line on the ticket.

| Label             | Next action                                  |
| ----------------- | -------------------------------------------- |
| `needs-triage`    | Maintainer assesses the issue.               |
| `needs-info`      | Reporter supplies missing information.       |
| `ready-for-agent` | An agent can implement the specified change. |
| `ready-for-human` | A person takes the next step.                |
| `wontfix`         | Work stops.                                  |
